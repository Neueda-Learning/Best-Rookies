# Frontend (Vue 3)

这是第一阶段 MVP 前端，用于创建组合、查看组合、增删持仓。

## 1. 环境准备

- Node.js 18+
- npm 9+

## 2. 安装依赖

```powershell
cd C:\Users\Administrator\Desktop\Best-Rookies\frontend
npm install
```

## 3. 启动开发服务器

```powershell
cd C:\Users\Administrator\Desktop\Best-Rookies\frontend
npm run dev
```

默认地址是 `http://localhost:5173`，会请求后端 `http://localhost:8080/api/v1`。
